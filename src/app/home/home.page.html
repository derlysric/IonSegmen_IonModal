Guía y Uso de IonSegment

Los IonSegment son barras de navegación que organizan y filtran contenido dentro de una misma vista, mejorando la experiencia de usuario en aplicaciones móviles.

Filtrado de Contenido

Ideal para alternar entre categorías, estados o vistas sin cambiar de página.

Manejo de Eventos

Utiliza (ionChange) para capturar la selección del usuario en tiempo real.

Personalización

Permite incluir iconos, texto y personalizar los estilos CSS fácilmente.

Guía y Uso de IonModal

El componente IonModal es una ventana superpuesta que aparece sobre el contenido principal para solicitar información o mostrar detalles adicionales.

Tipos de Modales

Se puede implementar como cuadro de diálogo flotante o como tarjeta (*Sheet Modal*).

Uso con Inline Template

Se puede vincular fácilmente mediante la propiedad [isOpen] o mediante ModalController.

Paso de Datos

Permite enviar y recibir parámetros entre la vista principal y la ventana emergente.
